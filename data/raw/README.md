# Raw data

The respondent-level CGSS 2017 file is not redistributed in this repository.

Obtain CGSS 2017 through the official CGSS data service and place the SAV at
`data/raw/CGSS2017.sav`.

The historical reproduction was developed against the archived SAV described
in the root README. That archive includes 12 diagnostic variables added during
the dissertation workflow; Stage 01 removes them before analysis. See the root
README for the archived file fingerprint and compatibility note.
